🛡️ The POC Scope Boundary

Firm division between what proves the concept now versus later additions.

  • Single-page web application with retro clean tile aesthetic.
  • Drag-and-drop Excel file parser (.xlsx / .xls).
  • Instant diagnostic cards (row, column, and missing cell counts).
  • Clickable cleaning action toggles + optional prompt text input.
  • Active cartoon mascot processing screen.
  • Rule-based and instruction-aware spreadsheet cleaning engine.
  • Itemized What Changed & What Didn't audit log.
  • One-click download of the cleaned spreadsheet.
  • Polite error notice for unsupported formats and empty files.
  • Charts & Deep Analytical Reports: Preserved the focus on the cleaning trust loop first.
  • In-Browser Grid Editor: User downloads clean file to work in Excel.
  • Multi-Format Ingestion (CSV, JSON, SQL): Kept Excel-first to mirror real internship pain.
  • User Logins & Cloud History: Ephemeral in-memory processing.
  • Complex Mascot Animation Sequences: Subtle illustrations used instead.
  • Will not function as a chatbot or conversational text stream.
  • Will not attempt to clone Excel, Tableau, or Power BI.
  • Will not invent synthetic data or silently guess missing numbers without user consent.

✅ Checkable Acceptance Criteria

Observable evidence that will verify each behavior during the build in 5-build.

1. Ingestion & Validation Screen Check
  • Dropping an .xlsx file begins parsing and reveals diagnostics within 2 seconds.
  • Uploading a non-Excel file displays: "Please upload an Excel file, this format is not supported."
  • Uploading an empty workbook displays a polite empty-state notification.
2. Diagnostic Inspection Screen Check
  • Row count, column count, and null cell count match true workbook contents.
  • Diagnostics are formatted into readable cards without raw technical errors.
3. Cleaning Actions & Prompts Interaction Check
  • User can click to select or deselect cleaning action checkboxes.
  • User can type custom instructions into the prompt box (or leave blank).
  • Clicking "Clean Data" disables inputs and triggers processing state.
4. Mascot Processing Visual Check
  • Cartoon cleaning character graphic appears while cleaning runs.
  • Duplicate submissions are prevented while in progress.
5. Audit Log & Export Output Check
  • Change log lists specific actions under "What Changed" and "What Didn't Change".
  • "Download Cleaned File" button downloads valid, uncorrupted Excel/CSV file.
