Messy Data Cleaner — Blueprint

Technical architecture: React (Vite) frontend + FastAPI (Python + pandas) backend with Google Gemini AI for smart instructions.

💡 How This Works, In Plain Language

A clean division of responsibilities designed for high trust, rapid development, and easy demo recording.

The Big Picture: The React frontend gives you an interactive, animated single-page surface (with file drag-and-drop, diagnostic counters, and mascot state). The FastAPI backend runs locally in Python, reading the Excel file with pandas, executing cleaning operations, calling Google Gemini API for custom instructions, and returning a detailed "What Changed & What Didn't" audit log.
Frontend UI
⚛️ React 18 + Vite
Single-page application with stage-based state, custom drag-and-drop, and cleaning controls.
Backend Engine
⚡ FastAPI (Python)
Asynchronous Python API handling file uploads, validation, and streaming clean exports.
Data Processing
🐼 pandas + openpyxl
Fast, deterministic spreadsheet manipulation: whitespace stripping, row/col cleanup, audit diffing.
Smart Prompts
✨ Google Gemini API
Interprets optional plain-English custom instructions into pandas code with audit notes (free tier).

🧩 Component Directory

Click each piece to see its file path, responsibilities, and PRD mapping.

frontend/src/components/DropZone.jsx

Role: Drag-and-drop file target. Checks file extension (.xlsx, .xls). If invalid, triggers polite inline alert without network call. Implements prd.md > Features and Behavior (1. Excel File Ingestion & Validation).

frontend/src/components/DiagnosticsPanel.jsx

Role: Renders diagnostic cards showing total rows, columns, and missing cells count/percentage. Implements prd.md > Features and Behavior (2. Workbook Breakdown & Diagnostic Summary).

frontend/src/components/CleaningControls.jsx

Role: Interactive checkboxes for cleaning actions (remove empty rows, trim whitespace, standardize headers) and free-text custom instruction input. Implements prd.md > Features and Behavior (3. Interactive Cleaning Prompts).

frontend/src/components/MascotLoader.jsx

Role: Active cartoon mascot visual with progress copy ("Tidying up your rows and sweeping nulls...") displayed during API execution. Implements prd.md > Features and Behavior (4. Mascot Processing State).

frontend/src/components/AuditLogResults.jsx

Role: Displays the "What Changed & What Didn't" audit lists and one-click "Download Cleaned File" button. Implements prd.md > Features and Behavior (5. Audit Log, 6. Clean File Export).

backend/cleaner.py

Role: Core Python pandas engine. Parses Excel buffer into DataFrame, runs selected cleaning routines, records audit log arrays, and outputs tidied Excel byte stream.

backend/gemini_helper.py

Role: Calls Google Gemini API (gemini-1.5-flash) to interpret custom text instructions into safe transformations. Graceful fallback if no key is set.

🔌 API Endpoints & Contracts

Exact contracts between React and FastAPI.

POST /api/scan

Takes uploaded Excel file, returns row/col/null counts.

POST /api/clean

Takes file + options + optional prompt, returns audit log & cleaned file.
