# Messy Data Cleaner

**A human-in-the-loop spreadsheet cleaner for transparent, explainable data cleaning.**

Messy Data Cleaner helps users identify common spreadsheet issues, choose how to clean their data, and review the changes before downloading the cleaned file.

The idea was inspired by my internship experience, where I noticed that people could be comfortable working in Excel but less confident with code-based data processing. I wanted to build something that makes data cleaning more accessible while keeping users involved in the process.

## Features

- **Data quality checks:** Identify common spreadsheet issues.
- **User-controlled cleaning:** Choose which cleaning operations to apply.
- **Transparent change log:** Review the changes made to your data.
- **Download cleaned data:** Export the cleaned spreadsheet.

## Try It Out

**Live demo:** https://dev-project-47zt.onrender.com

1. Upload a spreadsheet.
2. Inspect the detected data issues.
3. Choose the cleaning operations you want to apply.
4. Review the changes and change log.
5. Download your cleaned spreadsheet.

## Why This Project?

The goal is to make spreadsheet cleaning more approachable and transparent. Rather than cleaning data without user involvement, Messy Data Cleaner lets users review the issues and stay in control of the decisions made.

## Built With

Built with the help of an AI coding agent using an iterative, planning-led development process.
